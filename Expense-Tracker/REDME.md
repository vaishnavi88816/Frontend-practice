# Expense Tracker

A simple and responsive frontend Expense Tracker built using HTML, CSS and JavaScript.

## Features

- Add expenses
- Select expense category
- Add expense date
- View total expenses
- View total transactions
- Filter expenses by category
- Delete expenses
- Save data using browser localStorage
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in any web browser.

No backend or installation is required.
